# Writing Studio · «Пишемо разом»

Екран для запису відео: ліворуч завдання й графік, праворуч відповідь.

## Як відкрити
- Подвійний клік на `index.html` у Chrome (потрібен інтернет лише для шрифтів), або
- Завантаж папку на GitHub → Vercel (без налаштувань збірки), як і тренажери.

Адреса конкретного завдання: `index.html?t=line-1` (за замовчуванням `line-1`).

## Два режими (перемикач угорі)
**Сценарій.** Пробіл (або →) показує наступний крок: спочатку графік і дані, далі речення відповіді друкуються самі. Пробіл під час друку дописує речення миттєво. ← прибирає останній крок, R починає спочатку. Ліворуч графік підсвічує те, про що зараз речення (лінії, точки, цифри). Темп друку регулюється повзунком і запам'ятовується.

**Живий режим.** Пишеш сама в чотирьох полях (Introduction, Overview, Body 1, Body 2). Клік по легенді під графіком виділяє лінію. Кроки зверху клікабельні. Текст зберігається в браузері, «Перевірити» запускає чеклист.

## Клавіші
Пробіл / → далі · ← назад · R спочатку · F повний екран · C чистий екран для запису (ховає кнопки).

## Таймер
Кнопка ⏱ запускає 20 хвилин (стає помаранчевою за 5 хвилин до кінця), ↺ скидає.

## Нове завдання
1. Скопіюй `data/line-1.js` в `data/line-2.js` і заміни `prompt`, `chart` (дані, назви ліній) і `beats` (речення відповіді та підсвічування).
2. Відкрий `index.html?t=line-2`.

У `beats` кожне речення має `hl`: які лінії виділити (`s`), які точки підписати (`pts`: номер точки від 0), смугу між точками (`band`) і мітки (`tags`).
