      Автоперевірка — орієнтир, а не оцінка.

      0 слів · ціль 150–175

      Пробіл або → далі · ← назад · R спочатку · L підсвітити мову · F повний екран · C чистий екран

      Довідник по кнопках

      Режим «Сценарій»

      Пробіл → Enter
      Далі. Наступний крок. Якщо речення ще друкується, дописує його одразу.
      ← Backspace
      Назад. Прибирає останній крок.
      R
      Спочатку. Скидає все до початку.
      L
      Мова. Підсвічує наближення, порівняння й дієприкметники. Ще раз вимикає.
      Повзунок
      Темп друку. Правіше швидше. Запам’ятовується.
      Копіювати текст
      Копіює всю відповідь у буфер.

      Режим «Живий»

      Кроки зверху
      Клік переходить до кроку: Графік, Дані, Intro, Overview, Body 1, Body 2, Перевірка.
      Легенда під графіком
      Клік виділяє лінію, ще клік скасовує.
      Перевірити
      Чеклист: обсяг, структура, зв’язки.
      Копіювати текст
      Копіює відповідь.
      Очистити
      Стирає всі чотири поля.
      Автозбереження
      Текст лишається в браузері після перезавантаження.

      Для запису відео

      F
      Повний екран. Esc виходить.
      C
      Чистий екран. Ховає кнопки й підказки. Ще раз C повертає.
      A− / A+
      Розмір шрифту відповіді.
      ⏱ 20:00
      Таймер: клік запускає й зупиняє, за 5 хвилин до кінця стає помаранчевим.
      ↺
      Скидає таймер на 20:00.
      H ?
      Цей довідник. Закрити: Esc.

      Порядок запису відео

      1. F повний екран. Постав темп друку повзунком.
      2. C чистий екран (кнопки зникнуть), увімкни запис.
      3. Пробіл: графік, дані, речення по одному. Коментуй кожен крок.
      4. Наприкінці L: покажи наближення, порівняння, дієприкметники.
      5. Останній Пробіл показує чеклист.
